# Website design system

- Genre: editorial.
- Shape: long academic document with a restrained broadsheet front page.
- Theme: Hallmark Newsprint, adapted for an academic portfolio.
- Job: help academic readers assess research, publications, projects and CV, then make contact.
- Material: the existing portrait, academic YAML, CV and verified profile links. No invented proof.

## Visual system

- Paper: warm newsprint, never pure white; dark mode uses warm charcoal, never black.
- Ink: warm near-black in Light and warm paper ink in Dark.
- Accent: dried brick, limited to links, focus and active states.
- Display: Zilla Slab Bold. Body: Spectral Regular/Medium/Italic. Libre Franklin is used only for comparable figures.
- Rules carry structure: hairlines for ordinary seams, a double rule for major boundaries.
- Radius and shadow: none. Cards become rows, rules or paper wells.
- Photographs: monochrome with a factual caption and a one-pixel rule.

## Layout and components

- One capped 960px content measure with growing desktop gutters.
- Masthead navigation remains one line on desktop and the existing accessible menu on mobile.
- Homepage portrait and introduction form the lead; research metrics become a ruled box score.
- Long research, publication, project and CV records keep their sequence and semantic markup.
- Footer is a compact colophon with the existing accessible profile icons.
- All controls retain at least a 44px target, instant focus ring and keyboard behavior.

## Modes and motion

- Light and Dark have equal contrast and the same warm hue family.
- The existing automatic OS synchronization and temporary session override remain authoritative.
- State changes only; no entrance, parallax, carousel, transform-on-image or decorative animation.
- With JavaScript disabled, content and navigation remain available and CSS follows the OS theme.

## Preservation

- Preserve routes, IDs, links, citations, academic YAML, CV/PDF generation, portrait automation, SEO and accessibility checks.
- Preserve Hallmark Newsprint attribution and MIT reference provenance in the design documentation.
- Do not shorten or restate verified academic content to satisfy marketing-page word budgets.
