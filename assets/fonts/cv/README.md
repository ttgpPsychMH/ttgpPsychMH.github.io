# Bundled CV typeface

EB Garamond by Georg Duffner and Octavio Pardo, distributed under the SIL Open Font License 1.1. Original license and copyright notices are retained in [OFL.txt](OFL.txt).

The two original, unmodified variable TrueType files were obtained from Google Fonts at commit `47d54ca1ebb14fd864695f1d39dc734f39017c33`:

- https://github.com/google/fonts/blob/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/ebgaramond/EBGaramond%5Bwght%5D.ttf (local filename EBGaramond.ttf)
- https://github.com/google/fonts/blob/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/ebgaramond/EBGaramond-Italic%5Bwght%5D.ttf (local filename EBGaramond-Italic.ttf)

Files are bundled so PDF generation works offline without relying on host font installation. The sans-serif headings use the existing DejaVu Sans fallback available in the development/CI environment. No Geoff Boeing CV code or personal content is copied.
