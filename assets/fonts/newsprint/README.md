# Newsprint web fonts

These locally hosted fonts implement the Hallmark Newsprint direction without a runtime dependency on Google Fonts:

- Zilla Slab Bold: display headings and masthead.
- Spectral Regular, Medium and Italic: body, labels and emphasis.
- Libre Franklin variable: numeric figures only.

The original TTF sources were downloaded on 9 November 2026 from the corresponding `ofl/zillaslab`, `ofl/spectral`, and `ofl/librefranklin` directories in the [Google Fonts repository](https://github.com/google/fonts), then converted without modification to WOFF2 using FontTools.
